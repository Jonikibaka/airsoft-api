# Airsoft Classification API

Многомодальный API для автоматической классификации страйкбольного снаряжения. Система анализирует **текст объявления** и **фотографии**, чтобы определить категорию и подкатегорию товаров (оружие, экипировка, аксессуары).

## О проекте

Этот проект решает задачу модерации и категоризации товаров на досках объявлений.
*   **Анализ текста:** Извлекает сущности (например, "подсумки", "калашников") и определяет подкатегории.
*   **Анализ изображений:** Использует нейросеть YOLOv8 для классификации предметов на фото с точностью **~94%**.
*   **Мультимодальное слияние:** Сопоставляет результаты текста и фото для точного определения товара (например, если в тексте "M4", а фото подсумков).

##  Быстрый старт

### Требования
*   Установленный [Docker Desktop](https://www.docker.com/products/docker-desktop/)

### Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/Jonikibaka/airsoft-api.git
    cd airsoft.api
    ```

2.  **Проверьте наличие модели:**
    Убедитесь, что файл обученной модели лежит по пути:
    `runs/classify/runs/airsoft_cls_v1/weights/best.pt`
    *(Без этого файла контейнер не запустится)*

3.  **Запустите проект в Docker:**
    ```bash
    docker compose up -d
    ```

    **Важно:** Первый запуск может занять **10–15 минут**. Docker скачивает базовый образ Python, библиотеки (PyTorch, Ultralytics) и собирает приложение.
    **Последующие запуски** занимают 5 секунд.

4.  **Откройте документацию:**
    Перейдите в браузере: [http://localhost:8000/docs](http://localhost:8000/docs)

## 🔐 Аутентификация

API защищен ключом. Для работы через Swagger UI:
1.  Нажмите кнопку **Authorize** (🔒) в правом верхнем углу.
2.  Введите ключ: `SuperSecretKey`
3.  Нажмите **Authorize** → **Close**.

Чтобы изменить ключ, отредактируйте переменную `API_KEY` в файле `docker-compose.yml`.

Используйте эндпоинт `/predict-local`:
*   `post_id`: `test_001`
